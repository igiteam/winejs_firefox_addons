# Search Highlighted Text on Google Maps

Firefox addon. Highlight text on any page, right-click, choose "🗺️ Search on Google Maps".

Opens: `https://www.google.com/maps/search/<your-text>`

## Install
1. Open Firefox → `about:debugging`
2. This Firefox → Load Temporary Add-on
3. Select `manifest.json`

## Note
Temporary add-ons are cleared on Firefox restart. For permanent install, sign it at addons.mozilla.org or use an unsigned/dev build.
